# 便宜vps：看懂流量计费、机房和折扣叠加，建站、开服挑到够用又不踩坑的那台

搜「便宜vps」的人，预算其实早就想好了，卡住的是另一件事：这个价格到底便宜在哪，代价是什么。大厂轻量服务器年付几十块的秒杀价确实好看，但续费跳回原价、带宽是共享峰值；海外几美元一台的小鸡便宜，可国内访问的延迟和晚高峰丢包又劝退。便宜本身不难，难的是判断便宜背后的那一套规则你能不能接受。

这篇主要解决三件事：便宜 VPS 的钱是从哪省出来的、买之前必须算清哪几项隐藏成本、以及在这个筛选条件下雨云值不值得放进候选名单。

## 便宜 VPS 的钱，基本是从三个地方省出来的

**一是硬件分时复用。** 除了独享型产品，绝大多数低价 VPS 的 CPU 都是共享的，厂商卖的是"平均可用算力"而不是"独占的物理核心"。所以你 2 核 4G 的机器在邻居跑满的时候会明显变慢，这不是哪家的毛病，是这类产品的定价前提。低价套餐里 CPU 标称频率高不代表你能一直用到那个频率。

**二是计费模式。** 同样一台 2 核 2G，标"100M 带宽不限流量"和标"20M 带宽 300G 流量"完全是两个价格档。前者单价高、后者看着便宜，但后者在流量跑完之后会被限速——不是停机，是慢到基本没法用，得另外买流量包。

**三是活动价。** 首月五折、年付七折、拼团折扣、节假日促销，这些价格是真实存在的，但它们是"新购价"，不是"续费价"。把首月五折当作长期均价来算预算，是最常见的翻车方式。

## 买之前必须算清的四项隐藏成本

这部分没什么技术含量，但漏掉任何一项，你的"便宜"都会在第二个月蒸发掉。

**流量是双向计费的。** 雨云的流量型机型把上行和下行合在一起算，也就是你往外发数据、往里收数据都在消耗同一份额度。做网站、跑同步、开服，实际流量消耗往往比直觉快得多。

**流量用完是限速，不是停机。** 雨云的处理方式是用完额度后限速（不同机房限速档位不一样，有的是 5M，有的是 1M），想恢复高速得买流量包。好消息是每月用不完的流量可以累积叠加、次月不清零，跑得少的月份能攒下来。买之前先看清楚你选的机房属于"大带宽限流量"还是"小带宽不限流量"，同一台机器这两个版本价格有时能差二十块一个月。

**独立 IP 和硬盘是单独计价的。** 需要额外公网 IP 的话要另购，100G 高防 IP 大约 60 元/月；硬盘扩容按 GB 算，SSD 云盘大致在 0.3~0.4 元/GB/月这个区间。这些加起来，很容易把月付从 30 块推到 50 块。

**退款和试用都有次数上限。** 这类细节比价格更值得先确认，因为它决定了你试错的成本。

## 常见问题

**流量用完了会怎样？** 限速，不停机。不同机房限速档位不同，可以加购流量包恢复高速。每月剩余流量能累积到次月，不会清零。

**能装 Windows 吗？** 支持 Linux 和 Windows，部分地区可选 Mac 系统。装 Windows 会额外占用一部分内存和硬盘。
